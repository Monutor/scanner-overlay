Дизайн оверлея сканера

Как должен выглядеть экран поверх Telegram?

A

Текущий (карточка)

Белая карточка по центру на полупрозрачном фоне. Текст + камера внутри.

— Закрывает обзор, текст мешает

B

Fullscreen камера

Камера на весь экран. Сверху тёмная рамка сканирования (как в QR-сканерах).

+ Максимальная область захвата, привычный вид

C

Минималистичный

Камера на ¾ экрана сверху, снизу тонкая панель с кнопками без белого фона.

+ Есть место для кнопок, не закрывает всё
