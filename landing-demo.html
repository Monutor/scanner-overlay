Возможности

Всё, что нужно для работы со штрихкодами

Функции, которые реально ускоряют работу на складе

📷

Сканирование камерой

Мгновенное распознавание EAN-13, UPC, QR, Code 128, Data Matrix и других форматов через ML Kit. Настраиваемая точность, таймаут и отключение QR-кодов.

↗️

Автоввод в SEW

Accessibility Service автоматически вводит отсканированный код в нужное поле и отправляет форму. Поддержка Яндекс.Браузера, Chrome, Edge, Brave.

🪟

Плавающая панель

Компактная панель с кнопками сканера, выбора полки и поиска товара — поверх любого приложения. Настраиваемая прозрачность и размер кнопок.

🏪

Поиск полок и товаров

Встроенная база полок: сканируете штрихкод — получаете номер стеллажа, секции и уровень. TTS озвучивает голосом. Поиск товаров по артикулу через WebView.

🔧

Калибровка SEW

Двухточечная калибровка под ваш экран: укажите где кнопка «Ручной ввод» и «Готово» — приложение будет нажимать их автоматически.

🔲

QR-коды с ценников

Распознаёт QR на ценниках M.Video, извлекает артикул и ищет товар в базе. В SEW подставляется ШК, а не ссылка. Можно отключить в настройках.

🔄

Автообновление

Приложение само проверяет новые версии на GitHub и предлагает установить обновление. Базы полок и товаров синхронизируются автоматически.
